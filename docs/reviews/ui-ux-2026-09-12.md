# UI, recovery, and accessibility review — September 12, 2026

Baseline: `4046742` on `codex/weather-review-fixes`. Reviewed the web app and iOS simulator with separate core-flow, accessibility, recovery, and native reviewers. Implemented confirmed findings, rebuilt, and sent the fixes through an independent source and rendered-browser challenge. This report covers the local changes after that baseline; it does not represent a deployment.

## Findings and closure

| Finding | Change | Verification |
| --- | --- | --- |
| A failed city search displayed weather-service copy and could not retry the same query. | Search-specific error copy and an explicit **Retry search** action; the query and input focus survive. | Failure followed by successful retry in the browser; regression covers unchanged query and ignoring a late response after switching cities. |
| Removing a focused saved-place row dropped focus to the document. | Move focus to an adjacent saved-place selection, or to search when the list becomes empty. Only move focus when the removed control was focused. | Keyboard removal of adjacent and final rows; focused and unfocused removal regressions. |
| Opening or cancelling clear-data confirmation lost focus. | Focus **Keep my data** on opening and restore **Clear saved data** on cancellation. Link both choices to the confirmation description. | Before-fix regression failed; fixed test and independent browser keyboard replay passed. Initial mount does not steal focus. |
| Weather quota cooldown left an enabled retry control that silently did nothing. The empty forecast still promised it was on its way after failure. | Disable refresh buttons and pull-to-refresh during cooldown, display rounded remaining minutes, update at the deadline, and use waiting/unavailable copy outside loading. | Browser shows disabled countdown and accurate heading. Fake-clock regression verifies a 65-second deadline between normal clock ticks, skipped early requests, and successful retry at expiry. |
| Scrolled native content appeared behind status-bar text and the Dynamic Island. | Native-only fixed background covers the top safe area without intercepting input or changing layout. | Simulator Settings scrolling and Places input captures show a clear status bar; independent stacking/scope review passed. |
| Offline OpenAI guidance suggested switching to Apple Intelligence even when the simulator could not use it. | Offline copy asks the user to reconnect; the existing availability-gated switch control offers alternatives only when supported. | Independent provider-path review and focused briefing regressions passed; simulator replay checks the revised message. |

## Numbered flow health

1. **Today and forecast preview — healthy in reviewed states.** Current observation and preview remain separately labeled; preview shows a date/time and precipitation chance. Back to now restores current weather and slider focus. UV disclosure and weekly/hourly details remain readable. Wide layouts keep the intentional centered app column.
2. **Radar and location return — healthy in reviewed states.** Date/time, layers, legend, and controls are exposed; choosing Tokyo from Radar returns to Radar with an explicit outside-U.S.-coverage state. Reduced animation disables playback with an explanation. Narrow controls fit at 320 CSS pixels. The partial/blank basemap in one capture was not treated as a confirmed product defect.
3. **Places — fixed and re-reviewed.** Minimum-query and no-results guidance, clear search, saved counts, retry without editing, and keyboard focus after removal all passed.
4. **Settings — fixed and re-reviewed.** Unit selection updates temperature and wind. Clear-data confirmation gives the safe action focus, preserves contextual description, and restores focus on cancellation. Switches and volume controls remain labeled; 320-pixel reflow passed.
5. **Recovery — fixed and re-reviewed.** Welcome, denied location, empty search, service failure, quota, saved/offline, three-hour-old cache, delayed loading, and successful recovery were inspected. Saved observations retain timestamps and offline labels; refresh is disabled offline.
6. **iOS simulator — fixed and re-reviewed.** Updated Debug app built and installed on the iOS 26.5 QA simulator. Saved/offline Today, forecast preview and return to Now, Places input, native Settings, clear-data cancellation, and Radar offline fallback were inspected. Status-bar overlap and unsupported offline briefing guidance were corrected and independently reviewed. See the simulator addendum below.
